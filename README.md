# Enoch Thompson Portfolio

A responsive, theme-aware portfolio built with static HTML, CSS, and JavaScript.

## Run locally

```bash
npm start
```

Open `http://localhost:5173` in your browser.

## Deploy

Deploy the project root as a static site. No build command is required. The `_redirects` file provides direct access to the Work, Playground, About, and Contact routes on Netlify.

## Main files

- `index.html` — page content, routes, and SEO metadata
- `styles.css` — themes, responsive layouts, and motion
- `script.js` — routing, scroll reveals, and interactions
- `assets/` — optimized portfolio images and media
